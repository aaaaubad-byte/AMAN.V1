# نظام الهوية البصرية المنفذ — AMAN

**تاريخ التنفيذ:** 2026-10-07
**النطاق:** واجهات Compose لتطبيق العميل وتطبيق الإدارة، مع الحفاظ على محتوى الشاشات وعقودها وسلوكها الحالي.

> هذه قيم نظام تصميم اختيرت من القيم البرمجية القائمة وقراءة المراجع المرئية؛ ليست ادعاءً بأنها مواصفات أصلية رقمية للصور. الصور لا تحدد الخط أو القياسات أو تفاصيل التباين بدقة.

## الرموز المشتركة

| الاستخدام | القيمة / القرار |
|---|---|
| خلفية التطبيق | `#0B0F12` — القيمة الداكنة الموجودة سابقًا في ثيم الإدارة، واعتمدت للتطبيقين |
| السطح | `#111519` |
| السطح المرتفع | `#172027` |
| لون العلامة | `#FC0B39` — القيمة الموجودة سابقًا في Compose في التطبيقين |
| النص الأساسي | `#F5F6F7` |
| النص الثانوي | `#ADB7BD` — تسوية عملية بين القيم الحالية، وليست قياسًا أصليًا من الصورة |
| الحد والفاصل | `#263139` |
| نجاح الحالة | `#35C78A` للحالات الدلالية فقط، وليس لونًا أساسيًا للهوية |
| الخطأ | `#FF6B74` |
| الأشكال | صغيرة `10dp`، متوسطة `14dp`، كبيرة `18dp` |
| الخط | `sans` الافتراضي المتاح؛ لم يُضف خط خارجي لغياب أصل مرخص أو محدد |

تتضمن إعدادات النص ارتفاعات أسطر ومسافات مقروءة موحدة في العناوين والنصوص والملصقات. الثيمان موجودان في وحدتي Gradle منفصلتين؛ لذلك تتكرر الرموز في موضعي الثيم مع تعليق يفرض بقاء القيم متطابقة، بدل إنشاء وحدة مشتركة تزيد الترابط المعماري بلا مشاركة تشغيلية.

## قرارات الواجهة

- أُبقي اتجاه RTL ومحتوى العربية ووجهات الشاشات وشروط ظهورها كما هي.
- تستخدم الشاشتان ألوانًا متطابقة للأرضية والأسطح والحدود والنصوص والحالات، مع إبراز أحمر للعنصر النشط واستخدام الأخضر للنجاح فقط.
- أصبحت أيقونات شريط العميل السفلي أيقونات Material خطية بدل محارف نصية، وتستخدم أشرطة التطبيقين إبرازًا متسقًا للوجهة النشطة.
- أضيفت حدود هادئة للبطاقات والحالات الفارغة، وحد إبراز للبطاقات المحددة والتأكيدات، ومواءمة مرشحات الإدارة والتقارير مع لون العلامة.
- تستمد الحقول والأزرار والقوائم والحالات الافتراضية من رموز `MaterialTheme` نفسها؛ لم تُضف صور المراجع كخلفيات أو عناصر مقتطعة.
- لم يتغير منطق الأعمال أو المصادقة أو الصلاحيات أو تدفقات الشراء/الحماية أو قاعدة البيانات.

## الحدود والتحقق

- الصور المرجعية إدارية في معظمها؛ استُخدمت لتحديد الاتجاه العام الداكن/القرمزي والبطاقات وRTL، لا لإثبات مطابقة دقيقة لكل شاشة عميل.
- التطبيقان لا يحتويان أصلًا على ملف خط أو شعار مخصص يثبت من الصور. لذلك لا يُدّعى تطابق 100% في الخط أو الأبعاد أو تفاصيل الهوية الأصلية.
- القيم الرقمية أعلاه قرارات تنفيذية مستندة جزئيًا إلى القيم الموجودة مسبقًا في الشفرة.
