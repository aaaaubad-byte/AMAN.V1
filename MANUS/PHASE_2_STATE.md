# حالة AMAN — AMAN-2 / تطبيق Admin Android

## الحالة الحالية

**كود المصدر وعقود الإدارة موصولة على مستوى المستودع، والقبول الحي ما زال مفتوحًا.** لم تُتصل قاعدة Supabase المقصودة، ولم تُنفذ عليها migrations أو RPCs. migration `004_admin_provider_catalog_rpcs.sql` مصدر إضافي فقط. لا يُعد نجاح الترجمة/الاختبارات إثباتًا لتوافق البيئة الحية أو جاهزية الإنتاج.

## القرارات المثبتة

- **A04 — الأرقام:** لا يحرر Admin رقم الهاتف مطلقًا، ولا يوجد Admin Edit RPC لهذا الغرض. المتاح عرض العلاقة وعمليات الحالة/الأرشفة المسموح بها في العقد القائم.
- **A08 — الشركات:** إدارة Providers وTelecom Prefixes وProvider Tariffs عبر RPCs إدارية حقيقية مدققة؛ أضيفت migration مصدرية `004_admin_provider_catalog_rpcs.sql`. لم تُطبق على Supabase.
- تسليم الإشعارات للمستخدم النهائي يبقى في `notifications` بنوع `admin_alert`. سجل حملات الإدارة `admin_notifications` موجود أصلًا في migration 002؛ لم تنشئ migration 004 جدول إشعارات إضافيًا.
- لا `service_role` أو اعتماد على mock data. الجلسة واللقطات المحلية مشفرتان؛ Offline يسمح بالقراءة من cache فقط وتُعطل mutations.

## التحقق المنفذ

- `cd admin && ./gradlew testDebugUnitTest --no-daemon --console=plain` — **BUILD SUCCESSFUL** بعد آخر تعديلات المصدر؛ **7 اختبارات، 0 فشل، 0 أخطاء**. شملت المهمة ترجمة Kotlin الرئيسية واختبارات الوحدة، ولم تشغّل بناء/تصدير APK في هذا التحقق النهائي.
- SQL النهائي يطابق concatenation للمigrations `001`–`004` حرفيًا (`cmp` ناجح).
- فحص parser PostgreSQL غير متاح في هذه الجلسة الأخيرة (`ModuleNotFoundError: pglast`)، لذلك لا نزعم نجاح parser للمigration 004 ضمن هذا checkpoint. لا SQL منفذ.
- لم يُختبر التطبيق على محاكي/جهاز، ولم تتوفر قيم `SUPABASE_URL` و`SUPABASE_ANON_KEY` للمشروع المقصود.
- `git diff --check` وcommit/push إلى `main` هما خطوة إغلاق checkpoint الجارية؛ سيُسجل hash النهائي هنا بعد الإنشاء.
